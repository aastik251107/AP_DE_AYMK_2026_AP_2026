How a landowner query is handled

  1. Landowner files a query. The signed-in owner selects one of their own acquisitions and writes the reason.
  2. The backend checks ownership. It verifies the landowner is linked to the parcel, then saves the query as OPEN.
  3. Admin reviews it. Admin changes the status to UNDER_REVIEW while checking the issue.
  4. Admin records the outcome. The query becomes RESOLVED or REJECTED; the landowner can see the new status.
  5. Acquisition may finish. An acquisition cannot move to COMPLETED while a query is OPEN or UNDER_REVIEW, or while compensation is unpaid.

Each change is saved through the Express API and Prisma. The live event panel also receives an update.
